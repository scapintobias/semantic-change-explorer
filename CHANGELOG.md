# Changelog

## 1.0.0 — release-ready, 2026-09-21

- Arbitrary `.blend` comparison through separate script-disabled Blender processes.
- Deterministic neutral snapshot schema and independent Change IR.
- Conservative reciprocal matching, probable renames and unresolved candidate display.
- Authored transforms, structure, local mesh changes, sampled materials/modifiers, camera/light and custom properties.
- Separate evaluated mesh/world-transform observations at the saved frame.
- Portable GLB spatial viewer with linked selection, A/B/overlay/crossfade, fit and change navigation.
- Programmatically generated fixture demo, golden contracts, integration and browser tests.
- Consolidated installation and usage guidance for a shareable local workflow.

This branch is prepared for local sharing and installation as a release candidate in ordinary Python workflows. The project remains dependent on a separately installed Blender runtime, and compatibility is limited to the versions listed in the docs and build log.
