# Snapshot and Change IR are separate contracts

Status: accepted for v0.1 — 2026-09-21.

## Context
A snapshot observation does not establish correspondence or explain differences.

## Decision
Version two neutral JSON protocols. Store Blender details in a namespaced extension; allow a domain-effects callback.

## Alternatives
Diff raw JSON paths directly; put all logic in the viewer; use Blender-specific types everywhere.

## Consequences
More files and duplicated JSON, but independently testable matching/diff/renderers. CLI registration remains explicit, not a plugin framework.
