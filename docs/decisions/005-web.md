# React + TypeScript + Vite + Three.js

Status: accepted for v0.1 — 2026-09-21.

## Context
Selection, filters and 3D picking must stay coherent without a service backend.

## Decision
React owns UI state; a small imperative Three boundary owns scene resources; Vite emits static local assets.

## Alternatives
Vanilla DOM; Next.js; a large component kit; React Three Fiber.

## Consequences
Modest direct runtime set, a roughly 806 KB JS bundle before compression, explicit disposal and hand-written UI. No continuous render loop or state manager.
