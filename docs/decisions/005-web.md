# React + TypeScript + Vite + Three.js local browser app

Status: accepted for v1.0 — 2026-09-21.

## Context

The product is a local browser application. Users upload two `.blend` files through the browser, the backend processes them on loopback, and the same app moves directly into the comparison UI.

## Decision

React owns browser UI state; a small imperative Three boundary owns scene resources; a local Python loopback service owns the compare pipeline and temporary workspace lifecycle; Vite emits the browser assets served locally.

## Alternatives

Static report-only web app; CLI-first workflow; hosted upload service.

## Consequences

Modest direct runtime set, explicit disposal, loopback-only local processing, and no external file transfer. The browser is both the ingestion and result interface; the local Python service is the compute layer.
