# GLB from copied evaluated meshes

Status: accepted for v0.1 — 2026-09-21.

## Context
The browser needs portable geometry with reliable semantic mapping.

## Decision
Use Blender glTF export on temporary evaluated mesh copies with sce_entity extras. Solid material colors only.

## Alternatives
OBJ lacks rich scene metadata; custom mesh JSON increases rendering/transport ownership; native .blend browser parsing cannot reproduce dependency-graph evaluation.

## Consequences
Portable self-contained meshes, but no shader fidelity, camera/light geometry proxies, animation or decimation. Preview copying is in-memory only.
