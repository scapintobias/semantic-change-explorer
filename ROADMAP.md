# Roadmap

## Next

- Expand the verified Blender 4.5.14 LTS fixture coverage to real scenes and maintain a version/OS matrix.
- Observe designers and technical artists reviewing actual revisions; measure missed/incorrect interpretations before adding features.
- Add fixtures for linked libraries, disabled-driver evaluation and hidden/excluded collections.
- Make modifier/material nested differences more concise and navigable.
- Add non-mesh spatial proxies and relationship navigation.
- Measure memory and candidate density before indexing or simplifying large scenes.

## Later, subject to evidence

- User-confirmed match overrides with provenance, never silent certainty upgrades.
- Adapter SDK and one independently justified second domain.
- Compatible-topology displacement visualization; explicit indexing limitations.
- Git integration as an external comparison command, not storage ownership.
- Three-way read-only comparison, if it helps comprehension.
- Better report streaming and optional preview decimation with disclosed error.

## Explicitly not planned for v0.1

Merge, history storage, file hosting, accounts, cloud sync, remote collaboration, comments, project management, AI, a Blender sidebar product, full node-graph parity, every Blender domain, universal geometry equivalence or immediate CAD support.

Small genuine contributions are welcome: independently reproduced bugs, targeted generated fixtures, clearer semantic labels, portability testing, and documented uncertainty cases. No manufactured adoption metrics.
